# Shaarli Android

Shaarli Android 是一款轻量、易用的安卓客户端，专为 [Shaarli](https://github.com/shaarli/Shaarli) 书签服务设计。无论您是想快速收藏网页，还是高效管理您的书签，本应用都能提供无缝的体验。

## ✨ 功能亮点

*   **快速分享**：在任何应用（如浏览器、新闻客户端）中，只需点击“分享”按钮，即可将链接轻松保存到您的 Shaarli 服务中。
*   **用浏览器打开**: 针对某些没有“分享”按钮但提供“在浏览器中打开”选项的应用，本应用注册为浏览器来捕获链接。
*   **手动添加**：除了分享，您也可以在应用内手动添加链接或创建笔记。应用会自动获取链接的标题和描述，省去您手动输入的麻烦。
*   **全面的书签管理**：
    *   **查看与搜索**：在主页浏览您的所有书签，并使用强大的搜索功能快速找到所需内容。您可以按关键词、标签或可见性（公开/私有）进行筛选。
    *   **编辑与删除**：长按任何书签即可进入编辑模式，修改其标题、描述、标签或隐私状态。向左滑动则可轻松删除。
    *   **标签快捷搜索**：直接点击书签上的标签，即可快速查找所有包含该标签的链接。
*   **安全可靠**：您的 Shaarli 服务器地址和 API 密钥将被加密存储在设备上，确保您的账户信息安全无虞。
*   **轻量高效**：我们致力于保持应用的轻量化，减少不必要的依赖，为您提供一个体积小、资源占用低、响应迅速的工具。

## 🚀 如何使用

### 首次配置
1.  打开应用，点击主屏幕右上角的 **设置** 图标。
2.  输入您的 Shaarli **服务器地址** (例如 `https://myshaarli.domain.com`) 和 **API Secret**。
3.  根据您的偏好，设置链接的默认隐私状态（私有或公开）。
4.  点击 **保存**。配置完成后，您就可以开始使用了！

### 日常分享
1.  在浏览器或其他应用中，找到您想收藏的网页。
2.  点击系统的 **分享** 按钮。
3.  在分享菜单中，选择 **Shaarli Android**。
4.  应用将在后台自动为您保存链接，并显示一条成功提示。整个过程无需离开您当前的应用！



## 🛠️ 开发者信息

### 环境要求

*   Flutter SDK: [https://flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install)
*   Android Studio 或 VS Code（已安装 Flutter 插件）。

### 安装

1.  克隆仓库：
    ```bash
    git clone https://github.com/k997/shaarli_android.git
    ```
2.  安装依赖：
    ```bash
    flutter pub get
    ```

### 构建应用

要构建 APK 安装包，请运行以下命令：

```bash
flutter build apk --no-tree-shake-icons --split-per-abi
```

该命令会为不同的 CPU 架构生成独立的 APK 文件。您可以在 `build/app/outputs/flutter-apk/` 目录下找到它们。
